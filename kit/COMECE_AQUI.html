Servidor local

Depois de extrair o ZIP, abra um terminal na pasta principal do pacote. Com Node 24 ou superior já instalado:

node ab-mission-ipe/scripts/serve-presentation-kit.mjs

Abra http://127.0.0.1:4174. O build incluído funciona sem npm install. Esse modo serve a apresentação, o jogo com Worker e os documentos. Encerre com Ctrl + C.

A instalação inicial de Node e das ferramentas de desenvolvimento é separada do runtime offline.
